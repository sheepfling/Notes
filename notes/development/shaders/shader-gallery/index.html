How to read this page

The retained point-scatterer file is a helper library: it defines complex-amplitude functions but has no main() entry point. The preview supplies a small WebGL2 adapter that uses those exact helpers to plot phase interference.

Future GLSL files appear in the list automatically. A source file without a registered adapter is still browseable here, but the gallery will say so instead of rendering an unrelated approximation.

Start locally: uv run python scripts/serve_shader_gallery.py
