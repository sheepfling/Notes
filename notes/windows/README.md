# Windows and WSL notes

> Type: collection note  
> Status: current  
> Updated: 2026-08-01

These notes cover repeatable Windows, Windows Terminal, WSL2, hardware, and recovery procedures.
Machine-specific paths and crash artifacts were removed; commands use placeholders where a local
value is required.

## Topics

- WSL2 disk and distribution maintenance: [shrink a virtual disk](shrink-wsl2-vhdx.md),
  [move a distribution](wsl2-distribution-migration.md).
- Terminal setup: [make Git Bash the Windows Terminal default](windows-terminal-default-git-bash.md).
- Hardware troubleshooting: [RAM-upgrade blue screens](ram-upgrade-bluescreen.md) and the

Hardware notes are diagnostic guidance rather than proof of a single root cause. Establish a
known-good baseline and verify changes one at a time.
