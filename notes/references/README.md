# Reference archive

> Type: collection note  
> Status: needs-review  
> Updated: 2026-08-01

This collection holds broad reading lists and link archives that have not yet earned separate topic
notes. It is intentionally more archival than the technical collections: a link can remain here
while its usefulness, availability, or context is still being evaluated.

## Contents

- [Organized link archive](organized-link-archive.md) — 256 unique privacy-redacted links grouped by subject, plus preserved loose notes and a YouTube watch queue.

## Triage the archive

- Use the subject pages for links that still have enough context to be discoverable.
- Treat [Watch Queue](organized-link-archive/watch-queue.md) as a reading queue, not a validated
  source list.
- Treat [Scratch Notes](organized-link-archive/scratch-notes.md) as preserved context that may be
  promoted or discarded later.
- Use [Archives & Unresolved](organized-link-archive/archives-unresolved.md) for links whose
  destination or purpose is not yet clear.

Promote stable, reusable knowledge into a focused note when the link's purpose and verification are
clear. When a link is stale, private, or no longer useful, remove it rather than preserving it only
because it was once bookmarked.
